# Bundled third-party licence texts

Licence texts that must accompany the distributed application, copied verbatim
from the upstream package. Do not edit them.

| File | Component | Source |
|---|---|---|
| `pygame-LGPL-2.1.txt` | pygame 2.6.1 | `pygame/docs/generated/LGPL.txt` in the installed wheel |

The LGPL requires a copy of the licence to accompany the distribution, so this
folder is bundled into the application by `GetMoreDone.spec` and included in
every release archive. See `THIRD_PARTY_NOTICES.md`.
